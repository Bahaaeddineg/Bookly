## 📚 Bookly

The **Books App** is a simple mobile application that allows users to **browse and read books** directly from their device. It fetches data from a public **Books API** and was built to practice **clean architecture**, **state management**, and advanced Flutter features.

### 🔑 Features

* 📖 **Read Books Online**
  View full book content directly inside the app via a clean reading interface.

* 🌍 **API-Driven Content**
  All books are loaded dynamically from a live REST API.

* 🌗 **Light & Dark Theme Support**
  Users can switch between themes seamlessly for a comfortable reading experience.

* 🔁 **Reactive State Management**
  Built using the **Bloc** pattern for scalable and maintainable state flow.

* 🧩 **MVVM Architecture**
  Clear separation of concerns for easy maintenance and testing.

* 🚀 **Optimized Networking**
  Uses **Dio** for efficient API handling and custom interceptors.

* ⚠️ **Error Handling**
  Gracefully manages API errors, empty states, and loading indicators.
